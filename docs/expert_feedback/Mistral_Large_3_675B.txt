## **1. Immediate Computer Vision / Perception Fixes**
### **1.1 Tower HP Bar Detection: Dynamic ROI Anchoring**
**Problem:** Static ROIs fail due to vertical shifts in the HP bar (Δy ≈ 17px).
**Solution:** Use **contour-based landmark alignment** with template matching.

#### **Algorithm:**
1. **Landmark Detection:**
   - Detect the **level badge** (top-left corner) via template matching (OpenCV `matchTemplate`).
   - Use the badge’s bottom-right corner as an anchor `(x_anchor, y_anchor)`.
   - Scale offsets relative to this anchor (e.g., `y_hp_bar = y_anchor + 420`).

2. **Dynamic ROI Calculation:**
   ```python
   def get_hp_bar_roi(frame, template_badge):
       res = cv2.matchTemplate(frame, template_badge, cv2.TM_CCOEFF_NORMED)
       _, _, _, max_loc = cv2.minMaxLoc(res)
       x_anchor, y_anchor = max_loc[0] + template_badge.shape[1], max_loc[1] + template_badge.shape[0]
       roi_left = x_anchor + 120  # Relative to badge
       roi_top = y_anchor + 420
       roi_right = roi_left + 200
       roi_bottom = roi_top + 10
       return frame[roi_top:roi_bottom, roi_left:roi_right]
   ```

3. **HP Bar Parsing:**
   - Use **color thresholding** (HP bar is green/red) or **OCR** (Tesseract) for numeric HP.
   - For robustness, combine both:
     ```python
     def parse_hp(roi):
         # Color-based
         hsv = cv2.cvtColor(roi, cv2.COLOR_BGR2HSV)
         mask = cv2.inRange(hsv, (35, 100, 100), (85, 255, 255))  # Green
         hp_ratio = cv2.countNonZero(mask) / roi.size

         # OCR fallback
         hp_text = pytesseract.image_to_string(roi, config='--psm 7')
         return min(float(hp_text) / 1000, hp_ratio * 3346)  # Clamp to max tower HP
     ```

4. **Fallback: Contour Analysis**
   - If template matching fails, detect the **HP bar contour**:
     ```python
     def get_hp_bar_contour(frame):
         gray = cv2.cvtColor(frame, cv2.COLOR_BGR2GRAY)
         _, thresh = cv2.threshold(gray, 200, 255, cv2.THRESH_BINARY_INV)
         contours, _ = cv2.findContours(thresh, cv2.RETR_EXTERNAL, cv2.CHAIN_APPROX_SIMPLE)
         hp_bar = max(contours, key=cv2.contourArea)
         x, y, w, h = cv2.boundingRect(hp_bar)
         return frame[y:y+h, x:x+w]
     ```

     ```python
     def bbox_to_grid(bbox, mumu_res=(1080, 1920), grid_size=(18, 32)):
     ```

**Problem:** `exec-out screencap` + `input tap` introduces **800-1200ms latency**.
**Solutions:**

#### **Option 1: Minicap + Raw Framebuffer**
- **Minicap** streams frames via **socket** (≈100ms latency):
  ```bash
  adb shell LD_LIBRARY_PATH=/data/local/tmp /data/local/tmp/minicap -P 1080x1920@1080x1920/0 -S
  adb forward tcp:1313 localabstract:minicap
  ```
- **Python Client:**
  ```python
  import socket
  sock = socket.socket(socket.AF_INET, socket.SOCK_STREAM)
  sock.connect(("localhost", 1313))
  frame = sock.recv(1024 * 1024)  # Read JPEG header + frame
  ```

#### **Option 2: Scrcpy for Low-Latency Control**
- **Scrcpy** provides **<50ms latency**:
  ```bash
  scrcpy --no-display --v4l2-sink=/dev/video0 --no-audio
  ```
- **Frame Capture via V4L2:**
  ```python
  import cv2
  cap = cv2.VideoCapture("/dev/video0", cv2.CAP_V4L2)
  ret, frame = cap.read()
  ```

#### **Option 3: Shared Memory (Fastest)**
- **Android `ashmem` + `mmap`**:
  ```python
  # On Android:
  adb shell "su -c 'echo /dev/ashmem > /proc/self/fd/1'"
  ```

### **2.2 Predictive State Estimation & Action Queuing**
**Problem:** Hand-card state shifts before taps land (**149 rejected decisions/night**).
**Solution:** **Kalman Filter + Action Buffer**.

#### **Kalman Filter for Unit Tracking:**
```python
from filterpy.kalman import KalmanFilter
kf = KalmanFilter(dim_x=4, dim_z=2)  # x, y, vx, vy
kf.F = np.array([[1, 0, 1, 0], [0, 1, 0, 1], [0, 0, 1, 0], [0, 0, 0, 1]])  # State transition
kf.H = np.array([[1, 0, 0, 0], [0, 1, 0, 0]])  # Measurement function
kf.R = np.eye(2) * 5  # Measurement noise
kf.Q = np.eye(4) * 0.1  # Process noise

def predict_unit_position(measurements):
    kf.predict()
    kf.update(measurements[-1])
    return kf.x[:2]  # Predicted (x, y)
```

#### **Action Buffer with Deadline Scheduling:**
```python
from collections import deque
action_buffer = deque(maxlen=5)

def queue_action(card_slot, x, y, delay):
    deadline = time.time() + delay
    action_buffer.append((deadline, card_slot, x, y))
    action_buffer.sort(key=lambda x: x[0])  # Earliest deadline first

def execute_buffer():
    now = time.time()
    while action_buffer and action_buffer[0][0] <= now:
        _, slot, x, y = action_buffer.popleft()
        adb_tap(slot, x, y)
```
