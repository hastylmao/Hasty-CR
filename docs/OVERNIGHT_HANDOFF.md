## Review protocol (for whoever picks this up)

After each block, read the newest section of `tmp/live/overnight_report.txt` and compare against the previous block:

- `hog share of all plays` — should climb toward ~20%
- `cannon placements` x/y range — should stay inside x 8-10, y 20-22
- `SHIM veto` count — high counts mean the model is still spamming bad spells
- per-match `towers` — our two values vs enemy two; enemy values dropping means damage is landing

**Anti-stagnation rule:** if two consecutive blocks show the same dominant problem with no metric movement, do not re-tune the same constant a third time. Change approach instead — e.g. if forcing Hog is not converting to tower damage, the problem is support timing, not Hog frequency, so work on what gets played *with* it.
