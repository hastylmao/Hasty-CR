## 1. Immediate Computer Vision & Perception Fixes

### 1.1 Tower HP Bar: Dynamic ROI Anchoring via UI Landmark Regression

**Root Cause**: The HP bar's vertical offset shifts ±17px between matches due to dynamic UI scaling (device DPI, safe area insets, spectator mode overlays). Fixed pixel ROIs are brittle.

**Solution Architecture**: Two-stage pipeline—**landmark detection → relative ROI extraction → HP regression**.

#### Stage 1: Landmark Detection (Sub-ms CNN)
Train a tiny **YOLOv8n** or **MobileNetV3-SSD** to detect **three invariant UI anchors**:
- **Crown Icon** (top-left of each tower)
- **Level Badge** (bottom-right of each tower)
- **Tower Base** (bottom-center of tower sprite)

These are visually consistent across all resolutions and never occluded.

```python
# Pseudocode: Landmark Detector
class TowerLandmarkDetector:
    def __init__(self, model_path="tower_landmarks.onnx"):

    def detect(self, frame: np.ndarray) -> Dict[str, BoundingBox]:
```

**Training Data**: Synthesize 10k+ images by compositing tower sprites onto random backgrounds with random vertical shifts (±20px), scalings (0.95x-1.05x), and brightness variations.

### 1.2 Unit Detection: Segmentation & Temporal Fusion

**Problem**: Overlapping swarms (Skeletons, Bats) cause bbox NMS to merge into one detection, losing count and precise tile positions.

**Solution**: Switch from **bbox detection** to **instance segmentation** and add **temporal consistency**.

#### 1.2.1 Segmentation Model
Fine-tune **YOLOv8n-seg** on your dataset. Each pixel prediction yields:
- **Instance mask** → precise tile occupancy
- **Class label** → unit type
- **Confidence** → detection quality

**Post-processing**:
```python
def masks_to_tile_positions(masks: List[np.ndarray], 
                             grid_shape: Tuple[int, int] = (18, 32)) -> np.ndarray:
    """
    Convert binary masks to 18x32 occupancy grid.
    Each tile value = count of unit pixels in that tile.
    """
    grid = np.zeros(grid_shape, dtype=np.uint8)
    h, w = grid_shape
    mask_h, mask_w = masks[0].shape
    
    for mask in masks:
        # Downsample mask to grid resolution
        tile_counts = cv2.resize(mask.astype(np.uint8), (w, h), 
                                 interpolation=cv2.INTER_AREA)
        grid += tile_counts
    
    return grid  # Values 0-255, where e.g., 3 = 3 units in tile
```

#### 1.2.2 Temporal Fusion (Bayesian Filter)
Combat false positives/negatives with a **Kalman filter per tile** or simpler **exponential moving average**:

```python
class UnitTracker:
    def __init__(self, alpha=0.3):
        self.alpha = alpha  # Smoothing factor
        self.grid = np.zeros((18, 32), dtype=np.float32)
    
    def update(self, new_detection: np.ndarray):
        # new_detection: binary grid from current frame
        self.grid = self.alpha * new_detection + (1 - self.alpha) * self.grid
    
    def get_confirmed_units(self, threshold=0.5) -> np.ndarray:
        return (self.grid > threshold).astype(np.uint8)
```

This yields **sub-tile precision** and resolves swarm ambiguity.

## 2. Latency Reduction & Actuation Architecture

### 2.1 ADB Replacement: Scrcpy + Minicap Hybrid

**Benchmarks**:
- `adb exec-out screencap`: **800-1200ms** (PNG compression + base64 + TCP)
- **Scrcpy** (raw H264 + local socket): **50-80ms** (decode latency only)
- **Minicap** (direct framebuffer + WebSocket): **30-50ms** (fastest, but requires root)

**Recommended Architecture**: **Scrcpy** for non-root reliability + **async frame streaming**.

```python
# Production-ready Scrcpy client
import asyncio, struct
from scrcpy import ScrcpyClient

class LowLatencyFrameGrabber:
    def __init__(self, device_id="127.0.0.1:7555"):
        self.client = ScrcpyClient(device_id, max_fps=15)
        self.frame_queue = asyncio.Queue(maxsize=3)  # Drop old frames
    
    async def start_stream(self):
        async for frame in self.client.stream():
            # frame: np.ndarray (1080x1920 RGB)
            timestamp = time.time()
            if self.frame_queue.full():
                self.frame_queue.get_nowait()  # Drop stale
            await self.frame_queue.put((frame, timestamp))
    
    def get_latest_frame(self) -> Tuple[np.ndarray, float]:
        try:
            return self.frame_queue.get_nowait()
        except asyncio.QueueEmpty:
            return None, None
```

### 2.2 Predictive State Estimation & Action Queuing

**Problem**: 800ms latency means hand card state drifts between decision and execution.

**Solution**: **Game Clock Synchronization + Action Pre-Validation + Stale Decision Rejection**.

#### 2.2.1 Game Clock Sync
Clash Royale's elixir increments every **2.0 seconds** (server tick). Synchronize a local clock to the **elixir animation**:
```python
class GameClock:
    def __init__(self):
        self.elixir_history = deque(maxlen=10)
        self.tick_duration = 2.0  # seconds
        self.phase_offset = 0.0
    
    def sync(self, current_elixir: float, timestamp: float):
        """Fit phase offset to observed elixir changes."""
        self.elixir_history.append((current_elixir, timestamp))
        if len(self.elixir_history) >= 3:
            # Compute periodogram around 2.0s
            diffs = np.diff([e[1] for e in self.elixir_history])
            self.phase_offset = np.median(diffs) % self.tick_duration
    
    def predict_elixir_at(self, future_timestamp: float) -> float:
        ticks_ahead = (future_timestamp - time.time() + self.phase_offset) / self.tick_duration
        return self.current_elixir + ticks_ahead * 0.5  # +0.5 elixir/tick
```
